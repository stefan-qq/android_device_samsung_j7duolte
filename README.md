# Samsung Galaxy J7 Duo (SM-J720F) TWRP 3.3 branch

This branch builds the donor-era TWRP 3.3 userspace proven by the v22 test image
to provide UI and touch on the J720F stock Android 10 kernel and DT.

It keeps the exact J720F stock kernel, DT, legacy recovery geometry, PIT-backed
fstab, 39,845,888-byte recovery limit, and Samsung recovery trailer.

Build with the separate `TWRP-3.3-J720F.yml` workflow in the builder repository.
